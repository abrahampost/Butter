# Integration tests

Each case here is a complete `.butter` program run end to end through the
same loader → compiler → VM pipeline the CLI uses, with everything it
prints checked against a saved expected output — a black-box test of the
language, as opposed to the unit tests embedded in each `src/*.zig` file,
which test one stage (lexer, parser, compiler, VM) in isolation.

| File | Problem |
|---|---|
| [fizzbuzz.butter](cases/fizzbuzz.butter) | FizzBuzz, 1 through 20. |
| [factorial.butter](cases/factorial.butter) | `n!` for `n` in `0..10`, iteratively. |
| [fibonacci.butter](cases/fibonacci.butter) | `fib(n)` for `n` in `0..9`, recursively. |
| [bubble_sort.butter](cases/bubble_sort.butter) | Sorts a fixed-size array ascending, in place. |
| [sieve_of_eratosthenes.butter](cases/sieve_of_eratosthenes.butter) | Primes up to 30, via a `bool[]` sieve. |
| [gcd_lcm.butter](cases/gcd_lcm.butter) | Greatest common divisor and least common multiple. |
| [binary_search.butter](cases/binary_search.butter) | Binary search over a sorted array, including not-found. |
| [collatz.butter](cases/collatz.butter) | Collatz step counts for 1 through 20. |
| [array_stats.butter](cases/array_stats.butter) | Sum, float average, min, and max of an array. |
| [quadratic_formula.butter](cases/quadratic_formula.butter) | Quadratic roots via the bundled `math.std.butter`'s `sqrt`/`pow`. |
| [string_indexing.butter](cases/string_indexing.butter) | Hand-rolled `key=value;...` parsing via `s[i]` (single-character compare) and `s[a..b]` (slicing), plus basic index/slice reads. |

Each `<name>.butter` has a matching `<name>.expected` holding exactly what
it should print, byte for byte (generated by actually running the
program, not transcribed by hand). [integration_test.zig](integration_test.zig)
embeds both at compile time via `@embedFile`, runs the program in memory
(no subprocess, no real stdout), and diffs the captured output against the
`.expected` file with `std.testing.expectEqualStrings`. It also has a
couple of error-path cases (division by zero, an out-of-bounds index) that
assert on the `RuntimeError` returned instead, since there's no printed
output to compare for a program that's expected to fail.

Run just these:

```bash
zig build test-integration
```

Run everything (unit tests + these):

```bash
zig build test
```

To add a case: drop `<name>.butter` in `cases/`, run it once to capture
its real output into `cases/<name>.expected`, and add one `test { ... }`
block to `integration_test.zig` calling `expectCaseOutput("<name>")`.
